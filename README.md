# Merchant Fee Breakdown Calculator

**A statement total goes in. A clear fee breakdown, a trend and a merchant-ready PDF come out.**

▶️ **Live:** https://amarnate.github.io/fee-calculator-demo/

Explaining a merchant's processing fees by hand means a statement, a rate lookup, a calculator and an email, every month, for every merchant. This tool does it on one screen. It is a demo: the company (Acme Pay), the prices and the merchant are all fictional.

## What's in it

- **Fee switches.** Turn each fixed fee on or off and set its amount; add a custom fee with your own name for it
- **The breakdown.** Interchange, processor fee, per-item fees and fixed fees, each on its own line, with the effective rate
- **Scenario comparison.** What the merchant pays now next to what they would pay once compliant
- **Saved months and a trend chart.** Save each month, load one back to edit it, and see the rate move
- **Exports.** A clean PDF for the merchant and a detailed month-by-month report, each named with the business and the date
- **Demo data.** One button fills four fictional months
